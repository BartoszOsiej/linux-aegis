# AEGIS Code Audit — 2026-09-12

Full source review of the LSM (`aegis/`), devkit, and CI, with an in-tree
compile against the CI base commit
(`4d7d9486c04d917265f64c55bd23b2cc4fe7749c`) as proof. Every finding below
is fixed in the same commit that adds this document.

## Findings and fixes

### 1. Four of six sysctls were dead knobs (critical)

**Where:** `aegis/aegis_sysctl.c`

`ptrace_restrict_all`, `file_integrity_enforce`, `module_loading_denied`
and `syscall_audit_enable` wrote to static mirror variables only. The LSM
hooks read `aegis_cfg.*` — so `sysctl -w kernel/aegis/ptrace_restrict_all=1`
silently did nothing. `file_integrity_log` had no sysctl at all.

**Fix:** every handler now commits the mirror into the corresponding
`aegis_cfg` field after a successful write (macro-generated handlers), and a
`file_integrity_log` knob was added.

### 2. SHA-256 digest computation always failed (critical)

**Where:** `aegis/aegis_file.c`, `aegis_compute_file_hash()`

`crypto_shash_setkey(tfm, NULL, 0)` is invalid for unkeyed hash algorithms —
it returns `-EINVAL` unconditionally, so `hash_valid` could never become
true and every protected file showed `<pending>` forever.

**Fix:** the `setkey` call was removed (unkeyed SHASH needs only
`crypto_shash_init`).

### 3. Blocked-syscall list was never enforced (critical)

**Where:** `aegis/aegis_lsm.c`, `aegis/aegis_audit.c`

`aegis_is_syscall_blocked()` had zero call sites. The default block list
(kexec, init_module, finit_module, delete_module) was purely decorative.

**Fix:** enforcement added at the two LSM entry points that actually observe
these operations:

- `kernel_read_file`: `READING_MODULE` → `finit_module(2)`,
  `READING_KEXEC_IMAGE/INITRAMFS` → `kexec_file_load(2)`
- `kernel_load_data`: `LOADING_MODULE` → `init_module(2)`,
  `LOADING_KEXEC_IMAGE` → `kexec_load(2)`

Enforcement runs **before** the `MODULE_CONTROL` feature gate — the block
list belongs to `SYSCALL_AUDIT` and works even when module control is off.
`delete_module(2)` is documented as not reachable through current LSM hooks
(requires `CAP_SYS_MODULE` regardless).

### 4. `task->security = NULL` corrupted the LSM blob chain (critical)

**Where:** `aegis/aegis_lsm.c`, `aegis_task_alloc()`

AEGIS reserves no per-task security blob (`lsm_blob_sizes` is not set), so
`task->security` belongs to whichever stacked LSM allocated it. Writing
`NULL` clobbered that module's state and would crash its `task_free`.

**Fix:** the write was removed; the hook remains registered so the LSM
bookkeeping stays consistent.

### 5. File-permission hot path allocated memory on every file I/O (major)

**Where:** `aegis/aegis_lsm.c`, `aegis_file_permission()`

`file_permission` runs for every read/write on the system; the hook
performed two `kmalloc`/`kfree` pairs per call even when nothing was
protected.

**Fix:**

- early-exit when the protected-file list is empty (unlocked count read as
  a heuristic — never a correctness decision)
- one `__get_free_page` buffer replaces both allocations

### 6. Write protection could be bypassed via `open(2)` (major)

**Where:** `aegis/aegis_lsm.c`, `aegis_file_open()`

`file_permission()` does not run on `open(2)`, so `O_WRONLY|O_TRUNC` on a
protected file truncated it before any hook ran. The previous `file_open`
hook was an empty stub.

**Fix:** `file_open` now enforces the policy using the real open mode
(`FMODE_READ`/`FMODE_WRITE` → `MAY_READ`/`MAY_WRITE`). A fixed `MAY_WRITE`
here would have wrongly denied read-only opens — the mode is derived from
`f_mode`, not hardcoded.

### 7. securityfs: unchecked creation + incomplete teardown (minor)

**Where:** `aegis/aegis_securityfs.c`

`securityfs_create_file()` return values were ignored, and
`aegis_securityfs_exit()` removed only the directory — leaking five file
dentries.

**Fix:** every creation is checked with proper `PTR_ERR` propagation, a
failure mid-init unwinds cleanly, and teardown removes each file dentry
before the directory.

### 8. `kernel_read_file` could dereference a NULL `file` (minor)

**Where:** `aegis/aegis_lsm.c`

The `LOADING_*` variants of this hook can be invoked with `file == NULL`;
the module-load logging path dereferenced `file->f_path` unconditionally.

**Fix:** NULL guard before the `d_path` logging block; the buffer switch to
a free page applies here too.

### 9. `blocked_syscall_show` printed a `NAME` column with no names (trivial)

**Fix:** header now matches the data (`NR` only).

## Build verification

```
make olddefconfig && make -j4 security/aegis/
→ exit 0, zero errors, zero warnings, security/aegis/built-in.a produced
```

Compiled against upstream `torvalds/linux` at the CI base commit with the
repo's `build/aegis.config` and all four `patches/*.patch` applied — i.e.
exactly the CI pipeline, plus the new enforcement code paths the old CI
never compiled because the module predated them.
